# 📚 Estruturas de Dados em C++

> Repositório dedicado aos estudos e implementações da disciplina **Estruturas de Dados**, utilizando **C++**.

Este projeto documenta minha evolução no estudo de estruturas de dados fundamentais, algoritmos e técnicas de implementação, com foco na construção de uma base sólida para Engenharia de Software, Ciência de Dados e Desenvolvimento de Sistemas.

---

## 🎯 Objetivos

- Desenvolver raciocínio lógico e algorítmico.
- Aprender a implementar estruturas de dados do zero.
- Compreender análise de desempenho e eficiência.
- Aplicar conceitos em problemas práticos.
- Criar um histórico de evolução dos estudos.
